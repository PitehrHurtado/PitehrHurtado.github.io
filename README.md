# Pitehr Hurtado-Cayo - Academic Portfolio

Static site for [Pitehr Hurtado-Cayo](https://pitehrhurtado.github.io/), published with GitHub Pages.

## Publish

1. Push this repository to GitHub as `PitehrHurtado.github.io`.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`.
4. GitHub publishes the site at `https://pitehrhurtado.github.io/`.

## Before publishing

- Replace the `#` values for ORCID, Google Scholar, and LinkedIn in `index.html`.
- Replace `assets/img/profile-placeholder.svg` with your professional portrait. The layout is prepared for it.
- Replace the experience and presentation placeholders with your actual academic and professional record.
- Update the project descriptions and academic biography as your work evolves.
- Review every public detail. GitHub Pages sites are public; do not add credentials, private documents, personal identifiers, or unpublished research data.

No build step or external dependency is required.
